# PREDIAL · Sogamoso

Plataforma digital para la consulta ágil de viabilidad urbanística y normativa del POT de Sogamoso (Acuerdo Municipal 029 de 2016).

🌐 **Acceso web en vivo:** https://5antg.github.io/test/

## Módulos
- **Explorador:** Mapa satelital interactivo con georreferenciación y delimitación predial.
- **Ficha Normativa:** Diagnóstico automático de usos de suelo, tratamientos e índices volumétricos.
- **Simulador:** Semaforización en tiempo real de cumplimiento técnico.
- **Cesiones:** Calculadora de áreas públicas y cesiones obligatorias.
- **Planoteca:** Acceso directo a la cartografía oficial del POT.
- **Dossier PDF:** Generación instantánea de fichas normativas para exportación e impresión.
